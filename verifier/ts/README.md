# EyD verifier / site SDK — TypeScript

The business side of EyD for Node/TypeScript sites. Same wire formats
as the Python SDK ([../python/](../python/)): RFC 8785 canonicalization,
Ed25519 attestations, 15-minute sessions, PoT score gates, signed site
reports, offline receipt verification. Identity files are
byte-compatible — a key generated by either SDK loads in the other.

```bash
npm install
npm run build   # tsc -> dist/
npm test        # node --test, incl. Python-signed fixtures
```

```ts
import { EyDSite, Identity } from "eyd-verifier";

const site = new EyDSite(Identity.load("site.json"), {
  clearinghouseUrl: "https://clearinghouse.omni-ouro.com",
  domain: "eyd.example.com",
  callbackUrl: "https://eyd.example.com",
});
await site.enroll();
```

Per request, either wire the pieces yourself (`sessionAgent` →
`scoreAllows` → `passportStatus` → `report`) or use the Express
middleware in `eyd-verifier/express` (see `src/express.ts`): one
`app.post("/pay", eydGate(site, { minScore: 0.8 }), handler)` gives you
challenge/attestation, the score gate, Passport standing, refusal
reporting, and the fulfilled report.

Cross-implementation proof: `test/fixtures.json` is generated by the
Python SDK (`python test/gen_fixtures.py`) and every signature in it
must verify here; `tests/test_ts_verifier_interop.py` in the repo root
verifies the reverse direction.
